# Parchment Dual Enrollment — research study build

This repository hosts an **early-stage interactive prototype** used for an unmoderated
usability study. It is not a product, not a release, and not a reference implementation.

All data shown is fictional. Names, schools, colleges, courses, email addresses and
application records are invented for the study. Flows are stubbed or simplified, and
nothing here reflects shipped or planned behaviour.

## For the study team

**Generated output only — do not edit these files.** They are produced by a build script
kept outside this repository; anything changed here is overwritten on the next build.

The build is a deliberate **snapshot**: a study whose prototype changes mid-flight is
measuring two different products. `PROVENANCE.txt` records the source commit and build
time. Pull upstream changes forward between study rounds, not during one.
